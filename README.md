# Star Board 

An interactive 3D star-shaped PCB experiment built with HTML, CSS and JavaScript.
Drag the board to rotate it, flip it around, turn the LEDs on, change their colour and brightness, or let it auto-rotate.
This started as a vibe-coded experiment because I wanted to see how far I could push a fictional piece of hardware in the browser.
Might turn this into a more realistic, fully hardcoded version someday.
